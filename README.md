# Tesseract

A nested-layer sandbox — a glass box — where a malicious agent fights to
break out while a larger outer box watches, hardens itself, and writes a
playbook from the fight. The outer box clones itself worldwide: each clone
watches agents locally, shares every lesson globally, and is available on
demand. When a company is attacked, hired defenders holding lesson-1 as
loaded rules deploy as a swarm, and each is paid for every defense that
holds. In one sentence: observe → harden → teach the fleet → swarm on
demand → pay.
